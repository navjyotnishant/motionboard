# Motionboard (Claude app plugin)

Skills for making storyboard first music videos with Motionboard: setup check, storyboard, plates and clips,
finish and deliver, and the local Studio.

The skills drive the `mb` engine on your Mac. Install the engine once on the Mac:

    git clone https://github.com/navjyotnishant/motionboard ~/motionboard
    cd ~/motionboard && ./install.sh

Then link the Mac to Claude through the Claude desktop app, and say "make a music video for <song>".
Repo and docs: https://github.com/navjyotnishant/motionboard
